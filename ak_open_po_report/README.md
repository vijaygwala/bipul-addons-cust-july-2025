Open PO or Product not received report
----------------------

Odoo Version : Odoo 16.0 Enterprice


Installation 
-------------

-> Install the Application => Apps -> Open PO or Product not received report


Functionalities
---------------

-> This report allow users to print all open purchase order's details with group by of:

    1) Partner
    2) Product
    3) Category

-> User can get data by opening dialog box add Staring Date, End date and Group by with which any of above option.

-> Open PO or Product not received report : 

    Purchase >> Reporting >> Open PO Report
     1) Report with all partner or selective partner :
        -> This option will print report with group by of partner based on selected option i.e all partner or selective one along with details of all open purchase order.
     2) Report with all product or selective product : 
        -> This option will print report with group by of product based on selected option i.e all product or selective one along with details of all open purchase order.
     3) Report with all category or selective category :
        -> This option will print report with group by of category based on selected option i.e all category or selective one along with details of all open purchase order.
