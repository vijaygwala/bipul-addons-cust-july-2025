Assign Cashier on POS Orders on Odoo Apps

POS Order Sales Person odoo app helps users to add cashiers on pos order for specific products. Users can add, update or remove cashiers from the pos screen, users can also see added cashiers on pos order and see pos cashier on pos order pivot analysis report.

Features

Add POS Cashier.

User can add cashier for point of sale order with single click.

Update POS Cashier.

User can update cashier for specific or all product from pos screen.

Remove POS Cashier.

User can remove pos cashier for product from pos screen.

Cashier on POS Order & Analysis Report.

User can see added pos cashier on pos order and pos order analysis report.

Cashier Configuration

Under Point of Sale > Configuration > Settings user need to enable "Set cashier on pos order lines" option and also select cashier to allowed in POS session.

Add POS Cashier

User can see "Cashier" button on pos screen, Also see "cashier" icon after product on cart.

User can add cashier on specific product by clicking cashier icon on product, Also can add cashier for all product with single click by clicking "Cashier" button.

Select Cashier

On clicking "Cashier" button or icon new pop-up will open, User can choose cashier as per choice for product.

Added Cashier

User can see added cashier for all product.

Update Cashier

User can see update cashier for product by clicking "Cashier" button or icon for specific product.

User can select cashier for product.

Updated Cashier

User can see updated cashier for product.

Remove Cashier

User can remove selected cashier by clicking remove icon on product as shown bellow image.

Cashier on POS Order

User can see added cashier on pos order on back-end view.

POS Cashier on Analysis Report

User can see pos cashier on pos order analysis report.
